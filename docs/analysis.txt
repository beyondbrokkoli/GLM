NodeNumbering
Assigns a unique usize ID to every TableCtor, Index, BinaryOp, UnaryOp,
and their sub-expressions. Uses raw pointer keys (*const Expr -> usize) so
multiple analysis passes can cross-reference AST nodes without borrow-checker
issues. The map is populated once and never mutated — the AST Vec lives on the
heap for the entire compile. IDs are 0-based and contiguous for direct indexing
by flat arenas in shape.rs (site_elem, needed, verdicts).

AnalysisContext — Shared configuration and deterministic site mappings for compiler passes.
Pure data, no hidden state.

sites — Deterministic AST-node to Site-ID mapping.

max_flat_cells — At what size do we refuse to inline a Flat layout?

loop_escalation_weight — Threshold to assume a loop might execute many times (escalates lifetimes).

ast — A reference to the source AST for diagnostics.
