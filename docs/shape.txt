Sentinel: NULL_ROOT
NULL_ROOT = usize::MAX is the sentinel alias root meaning "this name has been
nil-ed / freed". It rides inside the aliases BTreeSet like a real site ID but
is NOT a site. ANY iteration over aliases must filter it out first:
  for s in &aliases { if *s != NULL_ROOT { site_elem[*s] } }
Dropping this guard causes an out-of-bounds panic at compile time.
Rule for edits: aliases iterate as "maybe NULL_ROOT", sites iterate as "never NULL_ROOT".

Ty::Record — Structural record type: `{field_a: Ty, field_b: Ty}` — heterogeneous fields.

ShapeFacts.substitutions — Substitution map from the type checker: Unknown ID → resolved type.
Populated by `TypeChecker::resolve_shapes()` after type checking
completes. Used by `elem_of()` to resolve Unknown element types.

[resolve_elem_type]
Resolve element types that the type checker may have unified.
Applies the substitution map to `Unknown(id)` types.

[elem_type_of_tbl]
Recursively resolve the element type of a table constructor.

[ty_to_static]
Recursively resolve the inner type of a table constructor.
CRITICAL: Uses `site_elem` for any inner tables that have been resolved
(to avoid infinite loops from Pending→Table mismatch in scope join).
