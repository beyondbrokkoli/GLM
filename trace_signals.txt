# trace_signals.txt — SINGLE SOURCE OF TRUTH for trace-plate signals.
#
# Every consumer agrees on this file:
#   build.rs parses it and generates the `pub const TRACE_*` items compiled
#   into src/trace.rs (duplicate slot or name = build error);
#   plate.py parses the same file to decode .glm_trace.bin.
# To add a signal: append one line on an unused slot, then poke it through
# the existing helpers. Never renumber, never double-book — the build fails.
#
# Grammar, one signal per line (blank lines and `#` lines are ignored):
#
#   <slot> <NAME> <owner> <meaning>
#
#   slot    0..=127, unique — the high half (128..256) is the per-run
#           counter mirror byte 128+N, not a slot namespace
#   NAME    A-Z 0-9 and _, unique; becomes TRACE_<NAME> in Rust
#   owner   single token: the subsystem that pokes it
#           (compiler, analyzer, backend, runtime)
#   meaning rest of line, verbatim
#
# Plate contract (docs/trace-plate.md): 256-byte classic plate — LOW half
# sticky booleans, HIGH half saturating per-run counters — plus the scope
# sections appended after byte 256.
